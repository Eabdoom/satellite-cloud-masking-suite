# CLOUD MASKING PROJECT CONTEXT & RUNDOWN FOR AI ASSISTANTS

This document serves as a developer handoff to get any LLM / AI coding assistant (like Gemini or Claude) up to speed on this codebase instantly.

---

## 🌟 Project Overview
This repository contains a productivity suite developed during an internship at **XDLINX Space Labs** to automate and manually touch up cloud masks for satellite imagery. The dataset is split into folders named `intern1` through `intern7`.

---

## 📂 Codebase Structure & Key Files

### 1. `gui.py` (PyQt5 Interactive Annotator)
An interactive PyQt5 application used to review and paint cloud masks.
* **Dual Drawing**: Allows the user to draw/erase masks on any of the three panels: Original Image, Mask, or Red-Overlay Image.
* **Translucent Red Overlay**: An opacity slider (and `self.mask_opacity` variable) allows adjusting how translucent the red cloud mask is, letting users see details underneath.
* **Up/Down Arrow Keys**: Real-time threshold adjustment. Pressing Up/Down adjusts the binary threshold value and dynamically slides the GUI threshold slider, regenerating the mask on the fly.
* **Keyboard Navigation**: Left and Right arrow keys switch between images and automatically save progress. Focus policies of other controls are set to `NoFocus` to prevent arrow key hijacking.
* **Custom Cursor**: The mouse cursor transforms into a cyan circle matching the exact size of the paintbrush.
* **Brush Sizing**: `[` to shrink, `]` to grow brush size.
* **Dynamic Dataset Selection**: Accepts dataset folder names as a command-line argument:
  `python gui.py intern6` (defaults to `intern5` if no argument is passed).

### 2. `kmeans_masker.py` (Advanced K-Means Cloud Masker)
An unsupervised, relative clustering algorithm used to automatically generate masks.
* **Algorithm**: Runs K-Means ($K=3$) to partition pixels into dark ground, haze, and bright cloud. It automatically extracts the brightest cluster center as the cloud mask.
* **Night Image Detection**: Checks if the average image brightness is less than `--night-threshold` (default `20.0`). If it is a night image, it bypasses K-Means and writes a clean, blank (all-black) mask.
* **Flags**:
  * `-l` / `--limit`: Limit the number of masks generated (useful for testing on 50 images).
  * `-f` / `--force`: Force overwrite existing masks (useful when folder already contains wrong masks).
  * `-n` / `--night-threshold`: Change the brightness cutoff for night detection.
* **Safety**: Hardcoded to refuse running on `intern3` and `intern5` to protect completed manual work.

### 3. `auto_masker.py` (Standard OpenCV Masker)
The original automation script. Uses a fixed binary threshold cutoff of `95` on grayscale conversions to generate masks.

### 4. `setup.bat` (Automated Installer)
A double-clickable script for Windows that:
* Creates a virtual environment (`venv`).
* Installs dependencies (`opencv-python`, `Pillow`, `PyQt5`, `numpy`).
* Configures `.vscode/settings.json` so VS Code automatically picks up the virtual environment python interpreter.

---

## 📊 Dataset Status

* `intern3` & `intern5`: Completed and finalized. **Do not run any automated scripts on these folders.**
* `intern1`, `intern2`, `intern4`: Datasets to be masked. Run `kmeans_masker.py` to pre-generate masks, then touch them up in the GUI.
* `intern6` & `intern7`: Contained wrong pre-existing masks. Pre-generated new ones using K-Means with the force-overwrite flag:
  `python kmeans_masker.py intern6 --force`
  `python kmeans_masker.py intern7 --force`

---

## 🚀 Common Commands Reference

```powershell
# Set up a new machine
.\setup.bat

# Pre-generate masks on a new dataset (e.g. intern1)
python kmeans_masker.py intern1

# Run K-Means and overwrite bad masks (e.g. intern6)
python kmeans_masker.py intern6 --force

# Test K-Means on just 10 images
python kmeans_masker.py intern1 --limit 10

# Run the GUI to inspect and touch up masks (e.g. intern6)
python gui.py intern6
```
